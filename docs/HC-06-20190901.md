# Referência validada — HC-06-20190901

Este documento registra o comportamento observado em bancada nos módulos HC-06
usados neste projeto. Ele não é um manual oficial do fabricante.

## Identificação

O módulo compatível responde:

```text
Comando:  AT+VERSION
Resposta: HC-06-20190901
```

O firmware do projeto exige essa resposta exata antes de alterar baud rate,
nome ou PIN.

## Configuração serial para comandos AT

```text
Bits de dados: 8
Paridade:       nenhuma
Stop bits:      1
Flow control:   nenhum
Final de linha: nenhum
```

Não acrescente `CR`, `LF` ou `CR+LF` aos comandos.

Um módulo novo opera normalmente em 9600 baud. Depois de configurado por este
projeto, passa a operar em 115200 baud.

## Comandos validados

| Objetivo | Comando | Resposta esperada |
|---|---|---|
| Testar comunicação | `AT` | `OK` |
| Consultar firmware | `AT+VERSION` | `HC-06-20190901` |
| Usar 115200 baud | `AT+BAUD8` | `OK115200` |
| Alterar nome | `AT+NAME<nome>` | contém `OKsetname` |
| Alterar PIN | `AT+PIN<pin>` | contém `OKsetPIN` |

Exemplo usado no projeto:

```text
AT
AT+VERSION
AT+BAUD8
AT+NAMELAB-EXPERT-BT
AT+PIN1234
```

## Temporização observada

- Aguarde cerca de 5 segundos após energizar o módulo antes do primeiro `AT`.
- Se não houver resposta, aguarde 5 segundos antes de tentar novamente.
- Evite enviar vários comandos AT em sequência rápida.
- Envie comandos AT somente enquanto não houver uma conexão Bluetooth ativa.

Esses intervalos foram necessários durante os testes com a Raspberry Pi Pico 2.

## Outras versões

Módulos comercializados como “HC-06” podem usar firmwares diferentes, como
variantes Linvor, e apresentar comandos ou respostas incompatíveis. Se
`AT+VERSION` não retornar exatamente `HC-06-20190901`, não presuma que esta
referência se aplica ao módulo.
